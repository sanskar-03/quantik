# Quantik Product Website

A responsive, single-page product website concept for **Quantik by YesPanchi**, using publicly available YesPanchi positioning as the content reference and drawing visual inspiration from the supplied UNIFAI and QSecura websites.

## Included
- `index.html` — complete landing page
- `styles.css` — responsive premium security design
- `script.js` — scroll progress, reveal animations, mobile menu

## Content approach
The site uses publicly described positioning around:
- Quantum Layer / quantum-safe payment security
- Harvest Now, Decrypt Later (HNDL)
- Post-quantum readiness
- ML-DSA / FIPS 204
- Cryptoagility
- Existing payment infrastructure integration
- Banking, FinTech, payment and enterprise use cases

It deliberately avoids unsupported customer names, performance numbers and certification claims.

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Deployment
This is static HTML/CSS/JS and can be deployed directly to Vercel, Netlify, GitHub Pages, or any static hosting service.
